## 🚀 Overview

A simple **Notes Management Application** built with **Laravel** and **Livewire**.  
Create, edit, delete, and filter notes — including marking them as **important** — all in real-time with Livewire.

---

## ✨ Features

- 📝 Create, edit, and delete notes  
- ⭐ Mark notes as important  
- 🔍 Filter to show only important notes  
- ⚡ Real-time updates (no page reloads)  
- ✅ Built with Laravel + Livewire  
- 💬 Flash messages for instant feedback

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone git@github.com:dionis1/notes-app.git
   cd notes-app

2. **Install dependencies**
   ```bash
   composer install

3. **Set up the environment**
   ```bash
   cp .env.example .env
   php artisan key:generate

4. **Set up the environment**
   ```bash
   php artisan migrate

5. **Set up the environment**
   ```bash
   php artisan serve

6. **Visit the application**
